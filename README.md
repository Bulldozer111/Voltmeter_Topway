# Бортовой вольтметр (Topway)

## Как получить APK без Android Studio
1. Создайте репозиторий на github.com и загрузите в него ВСЁ содержимое этой папки
   (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → сборка **Build APK** запустится сама
   (или нажмите *Run workflow*).
3. Когда сборка станет зелёной, откройте её и внизу в **Artifacts** скачайте `app-debug`
   (внутри `app-debug.apk`).

## Если на магнитоле по-прежнему «--.-V»
Запустите приложение → кнопка **«Диагностика»** → «Копировать»/«Поделиться»
и пришлите отчёт (файл также сохраняется как `voltmeter_report.txt`
в папке данных приложения). Найденный путь можно вписать в поле
**«Свой путь к файлу напряжения»**.
